# Ejemplos

Una carpeta por modelo, con un `debloat.txt` de paquetes que se pueden desactivar en ese firmware.

| Carpeta | Televisor | Sistema |
|---|---|---|
| `toshiba-emir-shandao/` | Toshiba Android TV (EMIR / Vestel shandao) | Android TV 11 |

Antes de aplicar la lista, comenta lo que uses. HDMI y Live TV se dejan.
